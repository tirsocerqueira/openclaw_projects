# Arquitectura: Despliegue (Deployment)

## Descripción
Despliegue local optimizado para un único nodo (portátil/servidor edge).

- **Orquestación:** Docker Compose.
- **Entorno:** Contenedores aislados para API, Frontend y motor de inferencia.
- **Almacenamiento:** Volúmenes persistentes en host para SQLite.
