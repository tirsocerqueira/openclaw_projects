# BinLevel

SaaS de monitorización inteligente de nivel de llenado de residuos mediante visión por ordenador.

## Descripción
BinLevel utiliza técnicas de regresión volumétrica para estimar el porcentaje de llenado (0-100%) de contenedores de basura, permitiendo optimizar rutas de recogida y evitar desbordamientos.

## Stack
- Python 3.12, FastAPI, SQLite
- YOLOv11n (para segmentación/estimación volumétrica)
- React + Vite
- Docker Compose
