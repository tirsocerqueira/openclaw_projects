# StockVision
SaaS de gestión automática de inventario mediante visión por ordenador.

## Descripción
StockVision utiliza YOLOv11n y ByteTrack para detectar, contar y gestionar stock en tiempo real mediante cámaras fijas o móviles, resolviendo roturas de stock y errores manuales.

## Stack
- Python 3.12, FastAPI, SQLite
- YOLOv11n, ByteTrack
- React + Vite
- Docker Compose
