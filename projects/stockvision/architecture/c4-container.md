# Arquitectura: C4 Container

## Descripción
Contenedores lógicos del sistema.

- **Web Frontend (React):** Interfaz para visualización de stock y configuración.
- **API (FastAPI):** Punto de entrada, gestión de inventario y endpoints.
- **Inference Engine (Python/YOLO):** Procesamiento de imágenes.
- **Database (SQLite):** Almacenamiento de SKUs, stock y logs de detección.
